AT SELECTION-SCREEN ON VALUE-REQUEST FOR S_CONTNO-LOW.

  " 1. ★ 서치헬프 팝업에 띄울 딱 두 개의 필드만 갖는 전용 타입을 만듭니다.
  TYPES: BEGIN OF TY_SHLP_CONT,
           CONTNO TYPE ZTG2SD0006-CONTNO,
           CUSTID TYPE ZTG2SD0006-CUSTID,
         END OF TY_SHLP_CONT.

  " 2. ★ 위에서 만든 전용 타입으로 인터널 테이블을 선언합니다.
  DATA: LT_CONT   TYPE TABLE OF TY_SHLP_CONT,  
        LT_RETURN TYPE TABLE OF DDSHRETVAL,
        LS_RETURN TYPE DDSHRETVAL.

  " 3. 필요한 두 개의 데이터만 가져옵니다. (STATUS 제외)
  SELECT CONTNO, CUSTID
    INTO CORRESPONDING FIELDS OF TABLE @LT_CONT
    FROM ZTG2SD0006.

  " 4. 서치헬프 호출 (이제 LT_CONT 구조대로 2칸만 예쁘게 나옵니다!)
  CALL FUNCTION 'F4IF_INT_TABLE_VALUE_REQUEST'
    EXPORTING
      RETFIELD    = 'CONTNO'
      VALUE_ORG   = 'S'
    TABLES
      VALUE_TAB   = LT_CONT
      RETURN_TAB  = LT_RETURN.

  READ TABLE LT_RETURN INTO LS_RETURN INDEX 1.
  IF SY-SUBRC = 0.
    S_CONTNO-LOW    = LS_RETURN-FIELDVAL.
    S_CONTNO-SIGN   = 'I'.
    S_CONTNO-OPTION = 'EQ'.
    APPEND S_CONTNO.
  ENDIF.

 계약을 체결하는 시점에 판매 오더 (1회차)가 생성되면서 이미
고객이 구독료를 지불 했다고 가정하기 때문에 매출전표를 판매 오더를 생성함과
동시에 발행할 수 있도록 데이터를 넘겨주는 게 좋겠다고 하네. 
SAPMZG2SD0003과  스케줄링 잡 프로그램인 ZRG2SD0013 에서 판매 오더를 생성하니깐
저 프로그램에 전표발행용 데이터를 넘겨주는 로직을 추가하면 되겠지? 


그러니깐 판매 승인 프로그램에선 매출전표 발행을 위한 데이터 삽입이 필요없을 거 같아.
